# Manual em subpasta

## Preparação

O caminho deste capítulo testa referências relativas a partir de subpastas. Consulte o [fluxo][arquitetura] e baixe o [arquivo com espaços](../../files/nota%20de%20operacao.txt).

Os capítulos são ordenados pelo caminho, o sumário é calculado pelo AWK e os ativos acompanham a publicação. Um link local inexistente deve reprovar a validação sem alterar a última saída válida.
